notice: The installer and launchers now keep a log of each run in %LOCALAPPDATA%\TAVI\logs, and launcher menu item 5 makes one zip to send when something goes wrong.

The Windows installer is now WINDOWS-install-TAVI-v1.4.0.bat. It runs one small simulation through TAVI itself and ends on INSTALLATION SUCCEEDED, INSTALLATION FAILED or TAVI INSTALLED, BUT THE TEST SIMULATION FAILED. It also offers a desktop copy of the TAVI Launcher shortcut. The launcher menu has a new item 5, Collect diagnostics for support, which zips the logs, the crash log and the TAVI Doctor's report. Exit is now the last item.
