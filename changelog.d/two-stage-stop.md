category: minor
notice: Stop now has two steps, and a force stop discards the point it interrupts; closing the window with a scan running asks first.

Stop Simulation finishes the current point and then ends the scan, and the button then reads Force stop; clicking it ends the McStas processes of the point in flight at once and discards that point, so a partial count is never recorded as a measurement. The same two steps apply to the Cancel button in the API dock, and a script can force-stop over the API with a kill field on both stop requests, which then reports how the scan was stopped. Long scans on the analytic engine no longer lock up the window: the plot, progress bar, counts and log update a few times a second instead of once per point, and the Stop click is handled promptly. Closing the window, or switching instrument, while a scan is running or queued now asks first (Keep running is the default) and stops the scan completely before TAVI closes or restarts.
