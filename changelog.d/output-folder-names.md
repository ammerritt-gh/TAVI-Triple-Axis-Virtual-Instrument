category: minor
notice: Save folders may now have umlauts, ß, accents and spaces in their names; a folder McStas cannot use is refused at Run with a message saying what to do.

Scan folders can now be named with umlauts, ß, French accents and spaces, and the scan runs in them; TAVI hands McStas the Windows short name of the folder, and the names TAVI shows and saves keep exactly what was typed. On a drive without short names (where Windows gives none), a folder McStas cannot use is refused when Run is pressed, before anything is simulated: the message names the folder, says what the problem is, and says to rename it or, on another drive, to choose a folder on C:. A folder name containing &, ^ or % is refused at Run on any drive.
