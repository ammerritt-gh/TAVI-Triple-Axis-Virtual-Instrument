category: major
notice: The psi and kappa corrections, the Misalignment panel and the motor-zero errors are gone, and old saved settings and old training codes are refused; a settings file from before this release is set aside as a backup and defaults are used.

The sample's hidden mount is now the only thing a training exercise hides: the psi and kappa corrections, the motor-zero errors and the Misalignment panel are removed everywhere, including the scan commands, the API and the saved settings. A scan of omega now turns the sample table (A3) itself, and an angle scan beside a Q, HKL or energy-transfer scan is refused, even with force, because one command would silently scan the other's quantity. A new training exercise is made only when its peaks can be reached within the instrument's motor travel, and a code from an older version, or a settings file saved by one, is refused with a message saying why instead of being half-loaded; the refused settings file is kept beside the original as a backup. A settings file that is not readable JSON, such as a truncated one, is set aside the same way instead of stopping TAVI from starting. A sample with no Bragg reflections, such as the phonon-only Al samples, offers no training exercise, and generation says why.
