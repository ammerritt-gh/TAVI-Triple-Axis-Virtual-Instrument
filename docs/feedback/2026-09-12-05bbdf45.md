## Organisation

**Two documents the agent file named as read-first were never in the repository (bit this session, fixed).** `docs/MCSTAS_PARAMETERS.md` and `config/TAVI-McStas-Path-Resolution.md` existed only on the operator's disk: `.gitignore`'s `mcstas_*` pattern matches `MCSTAS_PARAMETERS.md` case-insensitively on Windows, and `config/` swallowed the other. `AGENTS.md`'s "Before You Touch X" table and its reference list pointed at both. Every local reader read the operator's checkout and did not notice; an external reader of the public mirror got 404s. Fixed: `config/` became `config/*` (a directory pattern cannot be negated) with a negation for the parameters document; the path-resolution note turned out to be a superseded proposal and was absorbed into the installer design document and deleted. Latent lesson for the repository: an ignore pattern written for build artifacts (`mcstas_*`) can eat documentation, and `git ls-files '*.md'` is the check.

**Two documents in one repository disagreed and the agent file was the wrong one (bit this session, fixed).** `AGENTS.md` recommended calling the `tavi-dev` environment's `python.exe` directly for clean output, and the 2026-09-12 feedback record called the resulting full-suite crash "not reproduced". `TODO.md`'s Housekeeping section had explained it since 2026-09-09: invoked directly, the interpreter has `Library\bin` off PATH and anything importing matplotlib or Qt dies with a delay-load fault (0xc06d007f). A reader trusts the agent file first. Fixed in AGENTS.md; the general point stands that a fact settled in TODO did not reach the agent file for three days.

**The installation README described a helper that does not exist (latent until read, fixed).** `installer/TAVI-Installation-README.md` described a shared `tavi-bootstrap.bat` that "all launcher scripts call". The installer writes three launchers from embedded templates; only `run-tavi.bat` bootstraps the compiler, inline, and the menu's shell option does not. An operator opening the "TAVI shell" and running Python by hand would have hit the compile failure the README said that option prevents.
