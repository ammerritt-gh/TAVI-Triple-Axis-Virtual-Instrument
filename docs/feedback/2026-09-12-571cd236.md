## Organisation

**`WIP.md` was absent and `DESIGN_GOALS.md` still is (bit the pilot, one
work-around; the goals file is still open).** The shared documentation standard
requires both files at the root of every repository at every profile. The audit
run had to create `WIP.md` from the standard's skeleton before it could record
its own board entry, and it did so correctly, but the goals file is still
missing, so an agent planning work here has nothing to check its work against
and no Inbox to write into. Its body is the operator's to write; nothing else
can supply it.

**The audit ledger is a new document class in this repository.**
`docs/audits/<region>.md` is a work queue: each entry carries evidence, a
concrete failure or payoff, a reproducer command, an effort range and a remedy
boundary, and is deleted by the commit that lands its fix. It is reached from
the map through its board entry. Nine entries are queued as of this record;
three are P1. Whoever picks one up should run its reproducer at their own head
first, because an entry whose reproducer now passes is already fixed and an
entry whose reproducer fails for a different reason than its stated failure has
decayed.

## Operator and agent surface

separately (bit the pilot, resolved inside the run).** Both runs built an
isolated copy under the system temp directory to run experiments without
touching tracked files, and each had to configure McStasScript for that copy
before any reproducer would execute. The reproducers now committed under
`docs/audits/repro/` carry a shared `_sandbox.py` helper that does this, so a
later session reproducing a finding does not have to rediscover it.

the repository root into `%TEMP%` failed with access denied on `conftest.py`
specifically. The run recovered by copying through `git archive` instead of a
filesystem copy, which is the more reliable route for this repository and worth
preferring from the start.
